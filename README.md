# EDM AUTO - Site V1

Site Vite + React pour EDM AUTO.

## Fichiers importants

- `package.json` : configuration npm valide JSON
- `index.html` : point d'entrée HTML
- `vite.config.js` : configuration Vite
- `src/main.jsx` : lancement React
- `src/App.jsx` : application complète
- `src/index.css` : design complet

## Publier sur Vercel

Réglages :

- Framework Preset : Vite
- Install Command : npm install
- Build Command : npm run build
- Output Directory : dist

## Attention

Ne colle jamais le contenu de `src/App.jsx` dans `package.json`.
`package.json` doit rester du JSON strict.
